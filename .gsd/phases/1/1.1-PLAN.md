<task type="auto">
  <name>Configure Prisma ORM with PostgreSQL Relational Schema</name>
  <files>
    prisma/schema.prisma
    src/lib/prisma.ts
  </files>
  <action>
    Set up Prisma ORM with models for multi-role users, clubs, opportunities, bookmarks, notifications, and NextAuth session adapter.

    Steps:
    1. Install `@prisma/client` and `prisma` CLI.
    2. Define `prisma/schema.prisma`:
       - `datasource db` with provider `postgresql` (or `sqlite` compatible fallback if local dev Postgres is offline).
       - Enum `Role`: `STUDENT`, `CLUB_OWNER`, `ADMIN`.
       - Enum `Category`: `HACKATHON`, `CTF`, `CODING_CONTEST`, `WORKSHOP`, `INTERNSHIP`, `COMPETITION`, `OTHER`.
       - Enum `OpportunityStatus`: `DRAFT`, `SUBMITTED`, `APPROVED`, `REJECTED`, `EXPIRED`.
       - Model `User`: `id`, `name`, `email` (@unique), `emailVerified`, `image`, `role`, `clubId`, relations to `Club`, `bookmarks`, `notifications`, `accounts`, `sessions`.
       - Model `Club`: `id`, `name`, `slug` (@unique), `description`, `logoUrl`, `websiteUrl`, `createdAt`, `updatedAt`, relations to `User` (owners) and `Opportunity`.
       - Model `Opportunity`: `id`, `title`, `description`, `category`, `officialUrl`, `deadline`, `startDate`, `endDate`, `location`, `status`, `clubId`, `createdById`, relations to `Club`, `Bookmark`, `Notification`.
       - Model `Bookmark`: `id`, `userId`, `opportunityId`, `createdAt`, unique constraint on `[userId, opportunityId]`.
       - Model `Notification`: `id`, `userId`, `opportunityId`, `title`, `message`, `type`, `read`, `emailSent`, `createdAt`.
       - NextAuth models: `Account`, `Session`, `VerificationToken`.
    3. Create singleton Prisma client helper in `src/lib/prisma.ts` handling development hot-reloading cleanly.
    4. Run `npx prisma generate` to generate the type-safe client.

    AVOID: Creating circular foreign keys without cascade delete policies.
    USE: Explicit `@relation` fields with `onDelete: Cascade` where appropriate.
  </action>
  <verify>
    npx prisma generate
  </verify>
  <done>
    Prisma schema parses successfully with `npx prisma generate`, emitting full TypeScript client types for `User`, `Role`, `Club`, and `Opportunity`.
  </done>
</task>
