<task type="auto">
  <name>Implement Bookmark API Endpoint and Interactive Bookmark Button</name>
  <files>
    src/lib/bookmarks.ts
    src/app/api/bookmarks/route.ts
    src/components/opportunities/bookmark-button.tsx
    src/components/opportunities/opportunity-card.tsx
  </files>
  <action>
    Build the backend bookmark persistence and client-side toggle button.

    Steps:
    1. Create `src/lib/bookmarks.ts`:
       - `toggleBookmark(userId: string, opportunityId: string)`: creates or deletes `prisma.bookmark` record.
       - `getUserBookmarkedIds(userId: string)`: fetches array of opportunity IDs bookmarked by the user.
       - Handles database errors gracefully with fallback storage.
    2. Create `src/app/api/bookmarks/route.ts`:
       - `GET`: verifies session, returns array of bookmarked opportunity IDs.
       - `POST`: verifies session (returns 401 if unauthenticated), toggles bookmark for given `opportunityId`.
    3. Create `src/components/opportunities/bookmark-button.tsx`:
       - Client component displaying bookmark icon (filled gold when active, outline when inactive).
       - If unauthenticated: opens `SignInModal` with helpful domain prompt.
       - If authenticated: toggles bookmark optimistically and sends asynchronous request to `/api/bookmarks`.
    4. Connect `BookmarkButton` to `OpportunityCard` and `OpportunityDetail`.

    AVOID: Blocking the UI while waiting for the bookmark API response; use optimistic state.
    USE: Tooltip or title attribute indicating "Save to personal list".
  </action>
  <verify>
    npm run build
  </verify>
  <done>
    `npm run build` succeeds; `/api/bookmarks` route handler is registered; bookmark button renders on all cards with optimistic toggle behavior.
  </done>
</task>
