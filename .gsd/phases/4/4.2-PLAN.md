# Plan 4.2: Main Admin Dashboard, Club Provisioning, and Opportunity Moderation

## Objective
Construct the central Main Admin Dashboard at `/admin`: role-based authorization restricting access strictly to `ADMIN` users, opportunity moderation queue (review, approve, reject, edit, delete across all clubs), club directory management (create/edit clubs), and user role provisioning (assigning `STUDENT`, `CLUB_OWNER`, `ADMIN` and linking club affiliations).
