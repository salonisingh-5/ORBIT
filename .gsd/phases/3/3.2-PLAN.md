# Plan 3.2: In-App Notification Center Bell & Feed

## Objective
Implement the student in-app notification center: notification bell trigger with live unread badge, dropdown feed displaying approaching deadline reminders and system updates, mark as read controls, and full session integration.

<task type="auto">
  <name>Build In-App Notification Data Layer and REST API</name>
  <files>
    src/lib/notifications.ts
    src/app/api/notifications/route.ts
  </files>
  <action>
    Construct the notification data model queries, reminder generation, and REST endpoint.

    Steps:
    1. Create `src/lib/notifications.ts`:
       - `getUserNotifications(userId)`: returns notifications ordered by `createdAt` desc.
       - `getUnreadNotificationCount(userId)`: returns count of unread notifications.
       - `markNotificationAsRead(userId, notificationId)`: marks single notification as read.
       - `markAllNotificationsAsRead(userId)`: marks all user's notifications as read.
       - Graceful memory store fallback when PostgreSQL is offline.
       - Automatic generation of deadline reminders for student's bookmarked opportunities.
    2. Create `src/app/api/notifications/route.ts`:
       - `GET`: verifies session, returns notifications list and unread count.
       - `PATCH`: verifies session, marks single notification or all as read.
  </action>
  <verify>
    npm test
  </verify>
  <done>
    Notification data queries and API route are registered and verified.
  </done>
</task>
