# Plan 3.3: Automated Transactional Email Reminders via Resend

## Objective
Implement the automated email reminder pipeline for approaching opportunity deadlines: Resend API integration, editorial HTML email templates, duplicate-send protection, cron-ready dispatch endpoint, and safe local development fallback.

       - `POST` / `GET`: verifies session or `CRON_SECRET` header, executes reminder processing, and returns execution summary.
