# Plan 3.1: Centralized Calendar View Mapping Event Schedules and Registration Deadlines

## Objective
Construct the centralized interactive calendar interface at `/calendar`: month grid navigation, date schedule inspector, timeline agenda list, and instant "All Opportunities" vs. "Saved Only" toggle.

## Context
Load these files for context:
- .gsd/SPEC.md
- .gsd/REQUIREMENTS.md
- src/lib/opportunities.ts
- src/lib/bookmarks.ts
- src/components/opportunities/bookmark-button.tsx
- src/app/calendar/page.tsx

  <name>Build Calendar Date Engine and Grid Components</name>
  <files>

  <action>
    Construct the calendar data utilities and visual presentation components adhering to the editorial beige design system.

    Steps:
    1. Create `src/lib/calendar.ts`:
       - `getCalendarDays(year: number, month: number)`: generates matrix of day objects for the 7x5 or 7x6 month grid including padding days.
       - `getOpportunitiesForDate(opportunities, date)`: finds items with deadlines on this date or active event windows.
       - Helper for matching date strings (YYYY-MM-DD).
    2. Create `src/components/calendar/calendar-month-grid.tsx`:
       - 7-column grid (Sun - Sat) with editorial styling.
       - Day cells with day number, today indicator, active selection ring, and event chips/dots:
         - Red/Amber chip for registration deadlines.
         - Gold/Paper chip for active event running dates.
       - Tooltip / click handler to select a date.
    3. Create `src/components/calendar/calendar-agenda-list.tsx`:
       - Chronological schedule list of upcoming deadlines and events.
       - Groups items by date with relative countdown badge.
       - Card item showing category, club byline, title linking to `/opportunities/[slug]`, bookmark button, and apply link.
    4. Create `src/components/calendar/calendar-view.tsx`:
       - Client controller managing active month/year, selected date, "ALL" vs. "SAVED" filter, and "Grid" vs. "Agenda" view toggle.
       - Summary bar showing deadline counts for the month.
       - If "SAVED" selected and user is unauthenticated, prompts to sign in.
  </action>
  <verify>
    npm test
  </verify>
  <done>
    Calendar utilities and grid components build and unit tests pass.
  </done>
</task>
